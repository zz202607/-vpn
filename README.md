# 极简 VPN

基于 mihomo (Clash Meta) 内核的一键代理客户端。界面极简、全中文提示，点一下就能用。

## 使用方法

**双击运行项目根目录的 `极简VPN.exe`**（exe 必须与 core/、config/ 文件夹放在一起）。

或者用 Python 运行源码：

    python app.py

界面操作：

- **连接**：启动内核并打开 Windows 系统代理，即可访问被墙网站
- **断开**：3 秒内恢复正常上网，不留任何代理残留
- **更新订阅**：从订阅链接刷新节点列表；已连接时内核自动重启，新节点立即生效

## 命令行模式

    python app.py --selftest   # 端到端自检（连接 → 访问 Google → 断开 → 查残留）
    python app.py --update     # 无界面更新订阅

## 安全与可靠性

- 内核仅监听本机地址（程序每次启动自动打安全补丁，订阅配置里的对外监听会被改掉）
- 订阅内容异常（非有效配置）时保留原配置不动
- 程序退出（含异常退出）自动清理系统代理并结束内核
- 启动时发现代理残留但内核没在跑，自动清掉
- 订阅链接保存在 config/subscription.txt（已被 .gitignore 排除，不会提交）
- 首次运行自动下载缺失的地理数据文件（含国内镜像加速）

## 目录结构

    app.py              # 主程序（GUI + 内核管理 + 系统代理开关）
    极简VPN.exe          # 打包好的可执行文件（不入 git）
    core/mihomo.exe     # mihomo 内核（不入 git）
    config/             # 订阅、内核配置、地理数据（不入 git）
